# VSK Panel Kit

- `VSKPanel-iOS`: aplicativo SwiftUI. Abra um projeto iOS App no Xcode e substitua o arquivo `VSKPanelApp.swift`. Consulte o README da pasta.
- `VSKPanel-PWA`: web app instalável na tela inicial do iPhone. Publique em HTTPS e consulte o README.

As versões armazenam dados separadamente. Login local de demonstração, sem servidor de autenticação.
