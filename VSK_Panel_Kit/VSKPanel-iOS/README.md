# VSK Panel iOS (SwiftUI)

1. Em um Mac, abra o Xcode e crie `iOS > App`, nome `VSKPanel`, interface SwiftUI, linguagem Swift.
2. Defina iOS 16.0 ou superior como Deployment Target.
3. Substitua o arquivo `VSKPanelApp.swift` do projeto pelo arquivo deste pacote.
4. Selecione um simulador ou iPhone conectado e pressione Run.

O login valida nome (3+ caracteres) e senha (6+ caracteres), mas é local e não autentica em servidor. Não use senha real. Preferências e perfis ficam em UserDefaults. A mira é uma prévia dentro do aplicativo, sem integração direta com o jogo.
